## 5. 원문 요약

### 필수
1. **PC 라이브 방송**: PC 화면 공유와 마이크로 방송 시작 · 종료. 탭 소리 또는 시스템 소리를 마이크 음성과 함께 송출. 다른 기기에서 실시간 시청. 시작 · 화면 공유 · 소리 송출 · 시청 · 종료 흐름 확인
2. **모바일 라이브 방송**: 휴대폰 카메라 · 마이크로 방송 시작 · 종료. 영상 · 음성 실시간 송출. 다른 기기에서 시청. 시작 · 송출 · 시청 · 종료 흐름 확인
3. **방송 관리 및 시청**: 제목 등 정보 등록 · 수정 · 삭제. 목록 · 상세 화면에서 선택해 시청. 방송 중 · 종료 구분, 종료 시 송출 중단. 서버 재시작 후에도 조회
4. **사용자 인증 및 인가**: 회원가입 · 로그인 · 로그아웃 · 인증 상태 관리. 로그인 사용자만 등록 · 송출. 수정 · 삭제 · 송출 제어 시 서버에서 인증 · 소유자 권한 확인. 비로그인 · 소유자 · 다른 사용자별 허용 · 거절 확인. 목록 조회 · 시청은 로그인 없이 가능
